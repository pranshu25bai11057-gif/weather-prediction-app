##  Project Overview

This project is a **Weather Prediction App** built using Python. It provides real-time weather information for selected cities and also predicts future temperature using basic Machine Learning.

The application uses a graphical interface where users can select a city and view:

* Current weather condition
* Temperature
* Pressure
* Weather description
* Predicted future temperature (AI-based)

---

## Features

*  Real-time weather data using API
*  User-friendly GUI using Tkinter
*  Temperature display in Celsius
*  Basic AI prediction using Machine Learning
*  Fast and simple to use

---

## AI Concept Used

This project uses **Machine Learning** with a simple algorithm called **Linear Regression**.

* The model is trained on past temperature data
* It learns patterns from the dataset
* It predicts future temperature

## Installation & Setup

Follow these steps to run the project:

### Clone the repository

```bash
git clone https://github.com/your-username/weather-app.git
cd weather-app
```

### Install required libraries

```bash
pip install pandas scikit-learn requests
```

### Get API Key

* Go to OpenWeather website
* Create a free account
* Generate API key
* Replace it in code:

```python
appid=YOUR_API_KEY
```
